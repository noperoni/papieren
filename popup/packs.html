    How a tell is written 
    3 like if you agree         # a phrase: language boxes only
2 /^rt if\b/                # a pattern, between slashes: at most 200 characters
1 name: crypto              # name: or bio:, a phrase or a /pattern/
2 emoji >= 5                # emoji, hashtags: counts
1 caps >= 0.6 <= 0.9        # caps: the share of capital letters, 0 to 1
1 lines >= 3                # lines: lines per sentence
-1 length >= 600            # length: characters
2 media: link               # image, video, gif, poll, link
1 domain: example.com       # a link to the host or any subdomain
-2 context: reply           # reply, quote, repost, original
-3 account: gold            # gold, grey, affiliate, blue checkmarks;
1 account: everywhere       # everywhere, offences, copy, recycled,
2 account: hidden-before    # hidden-before: what the database saw

    The weight comes first: -10 to 10, not 0, and a negative weight counts against a match. A # starts a note at the start of a line, or after a space when a space or the line's end follows it, so #giveaway stays a phrase. Notes are not kept when you save.
